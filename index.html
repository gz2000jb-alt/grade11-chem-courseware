① 反应热与焓变：ΔH = ΣE(断键) − ΣE(成键)
化学反应的本质是旧键断裂（吸收能量）与新键形成（释放能量）。切换反应，比较两根能量柱的高低：断键吸得多、成键放得少 → 吸热；反之为放热。
断键吸收 = 679 kJ
成键释放 = 862 kJ
反应热 ΔH = −183 kJ/mol
类型：放热反应

核心概念

  • 反应热（焓变）ΔH = H(生成物) − H(反应物)。放热反应 ΔH<0，吸热反应 ΔH>0。
  • 微观本质：断开旧键吸收能量，形成新键释放能量，两者差值就是反应热。
  • 热化学方程式必须注明物质状态 (g)/(l)/(s)，ΔH 与系数一一对应。

公式与推导

ΔH = ΣE(反应物键能) − ΣE(生成物键能)　单位：kJ/mol
例：H−H 436、Cl−Cl 243、H−Cl 431 kJ/mol → H₂(g)+Cl₂(g)=2HCl(g)：ΔH=(436+243)−2×431=−183 kJ/mol。放热反应 ΔH 为负——成键释放多于断键吸收。

生活连结

  • 暖宝宝：铁粉缓慢氧化放热，续航十小时。
  • 火箭用液氢液氧：燃烧释放巨大反应热转化为推力。
  • 自热米饭：生石灰遇水放热，加热饭菜。

常见迷思

  • ❌「放热反应不用加热就能发生」→ 引发反应要先越过分歧点（活化能），点火只是"起跑"。
  • ❌「ΔH 忘写正负号」→ 放热 ΔH<0、吸热 ΔH>0，正负号是结论的一半。
  • ❌「键能就是反应热」→ 键能是断开 1 mol 键吸收的能量，ΔH 是两类键能的差。

开场提问："燃烧明明放热，为什么还要先点火？"
活动：切换三个反应，让学生先预测两柱高低再看图；追问"若生成 4 mol HCl，ΔH 变多少？"（系数翻倍 ΔH 翻倍）。
总结金句："断键吸、成键放，差值正负定热向。"
② 盖斯定律：ΔH 与路径无关
反应热只由始态和终态决定，与一步完成还是分步完成无关。拖动两步的 ΔH，看"直连"总变与"分步"之和始终相等。
A→B：ΔH₁ = +60 kJ/mol
B→C：ΔH₂ = −20 kJ/mol
A→C：ΔH总 = ΔH₁+ΔH₂ = +40 kJ/mol
60
-20

核心概念

  • 盖斯定律：化学反应的反应热只与反应体系的始态和终态有关，与反应是一步完成还是分步进行无关。
  • 本质：焓是状态函数，"能量守恒"在热化学中的体现。
  • 用途：计算难以直接测定或无法发生的反应热（如 C + ½O₂ = CO）。

公式与推导

ΔH(总) = ΔH₁ + ΔH₂ + ΔH₃ + …
使用方法：把目标反应"拼"成已知反应的代数和——方程式怎么加减，ΔH 就怎么加减（含符号与系数）。

生活连结

  • 从一楼爬到五楼，走楼梯还是坐电梯，上升高度相同——焓变同理。
  • 煤先气化再燃烧与直接燃烧，释放的总热量相同。
  • 营养学计算食物"卡路里"正用到盖斯定律的思想。

常见迷思

  • ❌「方程式乘 2，ΔH 不变」→ ΔH 随系数同步翻倍，还要注意方向反转时 ΔH 变号。
  • ❌「分步反应热相加时顺序无所谓」→ 必须对齐目标反应的方向与系数再相加。

③ 化学反应速率：v = Δc / Δt
拖动温度、切换催化剂，看浓度—时间曲线变陡变缓：曲线越陡反应越快，半衰期越短。
速率常数 k = 0.020 s⁻¹
起始速率 v₀ = k·c₀ = 0.020 mol/(L·s)
半衰期 t½ = 34.6 s
298

核心概念

  • 化学反应速率 v = Δc/Δt（通常取正值），常用单位 mol/(L·s)。
  • 同一反应用不同物质表示的速率之比 = 化学计量数之比。
  • 影响因素：浓度、温度、压强（气体）、催化剂、接触面积。

公式与推导

v = Δc/Δt　｜　一级反应：c(t) = c₀·e^(−kt)，t½ = ln2/k
范特霍夫经验规律：温度每升高 10℃，速率约增大到原来的 2~4 倍。本面板取每 10K 翻倍；催化剂使速率常数增大（图中 ×4）。

生活连结

  • 食物放冰箱减慢变质速率；高压锅升温加快炖煮。
  • 双氧水消毒时冒泡慢，滴入血液（含过氧化氢酶）立即沸腾般放氧。
  • 汽车三元催化器把有害气体快速转化为无害气体。

常见迷思

  • ❌「速率一定是正值且用同一物质表示都一样」→ 数值随所选物质不同，比例=系数比。
  • ❌「升温只加快吸热方向」→ 正、逆反应速率都增大，只是增大的倍数不同。
  • ❌「催化剂越多速率越快」→ 达到饱和后效果不再增强。

开场提问："食物放冰箱为什么不容易坏？"

总结金句："温浓催面大，速率往上爬。"
④ 化学平衡：Q 与 K 的博弈
以合成氨 N₂+3H₂ ⇌ 2NH₃（放热）为例：拖动温度、压强，或"注入"NH₃ 扰动平衡，观察 Q 与 K 的关系和移动方向。
平衡常数 K = 100.0
浓度商 Q = 0.04
平衡移动方向：正向进行
300
1
0.2

核心概念

  • 化学平衡状态的特征：逆、等、动、定、变。
  • 平衡常数 K 只与温度有关；Q<K 正向移动，Q>K 逆向移动，Q=K 恰好平衡。
  • 勒夏特列原理：改变条件，平衡向"减弱"这种改变的方向移动（减弱不抵消）。

公式与推导

K = c²(NH₃) / [c(N₂)·c³(H₂)]　（只与温度有关）
本仿真：c(N₂)=c(H₂)=1 mol/L 固定，K(T)=100×2^(−(T−300)/10)（放热反应升温 K 减小）；加压时体积压缩，Q 增大但 Δn<0 使平衡正移。固体与纯液体不写入 K。

生活连结

  • 合成氨工业：适度低温 + 高压 + 催化剂 + 及时分离 NH₃。
  • 开汽水瓶：减压后 CO₂ 溶解平衡逆向，气泡涌出。
  • 高原煮饭温度不够——气压影响沸点，也影响气相平衡。

常见迷思

  • ❌「加催化剂平衡正向移动」→ 催化剂同等加快正逆速率，只缩短达平衡时间。
  • ❌「平衡时正逆反应都停止了」→ 是"动态平衡"，v正=v逆≠0。
  • ❌「增大压强一定正向移动」→ 向气体分子数减小的方向移动，本反应正向分子数减小才正移。
📝 老师备课卡
教学目标：会用 Q 与 K 判断平衡移动方向，说出加压/升温对合成氨的影响。
开场提问："为什么要及时把 NH₃ 液化分离走？"
活动：先升温度看 K 下降，再注入 NH₃ 制造 Q>K，让学生预测方向再验证。
总结金句："Q 比 K 定去向，减弱改变不抵消。"
⑤ 化学反应的方向：ΔG = ΔH − TΔS
焓与熵"两条腿"共同决定方向。拖动 ΔH、ΔS、T，看 ΔG–T 直线何时落入自发区（绿色）。
ΔG = ΔH − TΔS = −40 kJ/mol
结论：能自发进行
-100
-200
300

核心概念

  • 焓判据：体系倾向能量降低（ΔH<0）；熵判据：体系倾向混乱度增大（ΔS>0）。
  • 复合判据：ΔG = ΔH − TΔS < 0 时反应能自发进行。
  • "自发"只表示趋势，不代表反应一定快（还看速率）。

公式与推导

ΔG = ΔH − TΔS（ΔS 单位 J/(mol·K)，代入时注意 ×10⁻³ 换算 kJ）
四种组合：ΔH<0、ΔS>0 → 任意温度自发；ΔH>0、ΔS<0 → 任意温度不自发；ΔH、ΔS 同号时存在转变温度 T*=ΔH/ΔS。

生活连结

  • 冰在室温自动融化：ΔH>0 但 ΔS>0，高温下 ΔG<0。
  • NH₄NO₃ 溶于水吸热仍自发——熵驱动的典型。
  • 室温下水 spontaneous 结冰不会发生——熵减且吸热双重不利。

常见迷思

  • ❌「放热反应才能自发」→ 冰融化、N₂O₅ 分解都是吸热自发，熵在帮忙。
  • ❌「ΔH<0、ΔS>0 还要低温才自发」→ 这是最"铁"的自发组合，任意温度都自发。
  • ❌「ΔS 单位直接代入」→ ΔS 是 J/(mol·K)，ΔH 是 kJ/mol，必须换算。
📝 老师备课卡
教学目标：会用 ΔG 判断方向，能求转变温度。
开场提问："吸热反应就一定不能发生吗？举一个反例。"
活动：固定 ΔH、ΔS，拖 T 找直线与零轴的交点（转变温度）。
总结金句："焓熵合力定方向，温度天平两端晃。"
⑥ 弱电解质的电离平衡：Ka 与电离度
醋酸是弱酸，部分电离。拖动浓度与温度，看分子与离子的"势力消长"：越稀越电离，升温促电离。
Ka = 1.75×10⁻⁵
c(H⁺) = 1.31×10⁻³ mol/L
电离度 α = 1.31 %
pH = 2.88
0.10
25

核心概念

  • 强电解质完全电离；弱电解质部分电离，存在电离平衡：CH₃COOH ⇌ CH₃COO⁻ + H⁺。
  • 电离常数 Ka 只与温度有关，Ka 越大酸性越强。
  • 电离度 α = 已电离分子数/初始分子数 ×100%；稀释促进电离。

公式与推导

Ka = c(H⁺)·c(Ac⁻)/c(HAc)　｜　c(H⁺) ≈ √(Ka·c)（近似）
0.1 mol/L 醋酸（25℃）：c(H⁺)≈1.31×10⁻³ mol/L → pH≈2.88，α≈1.3%。"越稀越电离"：稀释 10 倍 α 增大但 c(H⁺) 减小。

生活连结

  • 食醋含 3%~5% 醋酸，弱酸部分电离所以"酸而不烈"。
  • 碳酸饮料开盖减压 CO₂ 逸出，平衡逆移酸性减弱。
  • 人体血液缓冲对维持 pH 7.35~7.45 稳态。

常见迷思

  • ❌「稀释后电离度增大，酸性增强」→ α 增大但 c(H⁺) 减小，pH 变大。
  • ❌「Ka 大小说明溶液浓度大」→ Ka 是性质常数，与浓度无关。
  • ❌「升温抑制电离」→ 电离吸热，升温促进电离。
📝 老师备课卡
教学目标：会用 Ka 近似式求 c(H⁺)、pH 与 α，理解"越稀越电离"。
开场提问："pH 相同的盐酸和醋酸，谁更浓？为什么？"
活动：拖浓度从 1 到 0.01，读 α 上升而 pH 上升（酸性减弱）。
总结金句："稀了电离多，离子反倒薄。"
⑦ 水的电离与溶液 pH：pH = −lg c(H⁺)
水的离子积 Kw 是酸碱的"总开关"。拖动 pH 看色带与液体颜色；升温看"中性点"其实不在 7。
c(H⁺) = 1.0×10⁻⁷ mol/L
c(OH⁻) = 1.0×10⁻⁷ mol/L
Kw = 1.0×10⁻¹⁴
酸碱性：中性
7.0
25

核心概念

  • 水是极弱的电解质：H₂O ⇌ H⁺ + OH⁻，Kw = c(H⁺)·c(OH⁻)，25℃ 时为 10⁻¹⁴。
  • Kw 只与温度有关；升温促进水的电离，Kw 增大。
  • 酸碱性看相对大小：c(H⁺)>c(OH⁻) 为酸性；中性时二者相等（不一定等于 10⁻⁷）。

公式与推导

pH = −lg c(H⁺)　｜　pKw = pH + pOH
25℃：pKw=14，中性 pH=7。升温 pKw 减小（100℃ 约 12.1），中性 pH≈6.1——此时 pH=7 反而是碱性！

生活连结

  • 洗发水弱碱性去油，护发素弱酸性护发，一洗一护。
  • 鱼塘水质监测：pH 突变提示水体污染。
  • 胃液 pH 1~2，饭后短暂升高又恢复。

常见迷思

  • ❌「pH=7 一定是中性」→ 要看温度，升温中性点小于 7。
  • ❌「酸稀释 100 倍 pH 变 14」→ pH 只能无限接近 7，水也在电离。
  • ❌「pH 相差 1 只是差 1」→ c(H⁺) 相差 10 倍。
📝 老师备课卡
教学目标：会进行 pH 与 c(H⁺)、c(OH⁻) 的互算，理解 Kw 随温度变化。
开场提问："100℃ 的热水里，pH=7 还算中性吗？"
活动：先拖 pH 看色带与酸碱性，再固定 pH 拖温度观察中性点漂移。
总结金句："pH 是负对数，十倍一档别记错。"
⑧ 盐类的水解：谁强显谁性
选一种盐、调一个浓度：强酸强碱盐"按兵不动"，含弱离子的盐则"拉着"水反应，溶液酸碱性随之改变。
溶液 pH = 7.00
酸碱性：中性
水解方程式：不水解
0.10

核心概念

  • 水解本质：盐电离出的弱酸根/弱碱阳离子与水电离出的 H⁺ 或 OH⁻ 结合，破坏水的电离平衡。
  • 规律：有弱才水解，谁强显谁性，越弱越水解；强酸强碱盐不水解。
  • 水解是吸热反应，升温促进水解。

公式与推导

NH₄⁺+H₂O ⇌ NH₃·H₂O+H⁺，Kh = Kw/Kb　｜　c(H⁺) ≈ √(Kh·c)
0.1 mol/L NH₄Cl：Kh=10⁻¹⁴/1.8×10⁻⁵≈5.6×10⁻¹⁰，c(H⁺)≈√(5.6×10⁻¹¹)≈7.5×10⁻⁶ → pH≈5.1（弱酸性）。

生活连结

  • 纯碱（Na₂CO₃）去油污：水解显碱性，加热促进水解效果更好。
  • 泡沫灭火器：Al₂(SO₄)₃ 与 NaHCO₃ 双水解互相促进产生 CO₂。
  • 化肥：铵态氮肥不宜与草木灰（碱性）混用。

常见迷思

  • ❌「水解方程式用 = 且彻底」→ 水解微弱，用 ⇌ 且不标 ↑↓。
  • ❌「所有盐都水解」→ 强酸强碱盐（NaCl）不水解。
  • ❌「中和反应都放热所以水解放热」→ 水解是中和的逆过程，吸热。

⑨ 沉淀溶解平衡：Ksp 与 Q 的比较
AgCl(s) ⇌ Ag⁺ + Cl⁻。调两种离子浓度，Q 与 Ksp 一比：过饱和析出、不饱和溶解。
Q = c(Ag⁺)·c(Cl⁻) = 1.0×10⁻⁴
Ksp(AgCl) = 1.8×10⁻¹⁰
状态：Q>Ksp：析出沉淀
-2.0
-2

核心概念

  • 沉淀溶解平衡：固体溶质与溶液中离子间的动态平衡，如 AgCl(s) ⇌ Ag⁺ + Cl⁻。
  • Ksp（溶度积）只与温度有关；同类型沉淀可直接比较 Ksp 判断溶解能力。
  • 离子积 Q 与 Ksp 比较：Q>Ksp 生成沉淀；Q=Ksp 平衡；Q<Ksp 不饱和。

公式与推导

AgCl(s) ⇌ Ag⁺ + Cl⁻　｜　Ksp = c(Ag⁺)·c(Cl⁻) = 1.8×10⁻¹⁰
沉淀转化规律：Ksp 小的沉淀更难溶，可由易溶向难溶转化（BaCO₃ + SO₄²⁻ → BaSO₄ + CO₃²⁻）。

生活连结

  • 钡餐用 BaSO₄（Ksp 极小不溶解）而不用有毒的 BaCO₃（胃酸可溶）。
  • 龋齿：酸性环境溶解牙釉质（羟基磷灰石）的溶解平衡。
  • 硬水水垢：CaCO₃、Mg(OH)₂ 沉淀析出。

常见迷思

  • ❌「Ksp 越小溶解度一定越小」→ 只有同类型沉淀才可直接比较。
  • ❌「加越多水沉淀溶得越多」→ 溶解有限，注意溶度积的表达式。
  • ❌「沉淀完全=离子浓度为零」→ 只是离子浓度降到极低（<10⁻⁵ mol/L）。

教学目标：会用 Q 与 Ksp 判断沉淀的生成与溶解。

⑩ 原电池：化学能 → 电能
锌铜稀硫酸电池：锌失电子被氧化（负极），氢离子在铜片上得电子冒泡（正极）。看电子"跑"外电路、离子走溶液。
负极：Zn − 2e⁻ = Zn²⁺
正极：2H⁺ + 2e⁻ = H₂↑
电子流向：Zn → 导线 → Cu
c(H⁺) = 2c(H₂SO₄) = 1.0 mol/L
反应剧烈程度（相对 0.5 mol/L 基准）：1.0×
0.5

核心概念

  • 原电池把化学能转化为电能：自发的氧化还原反应拆成两半，电子经外电路转移做功。
  • 负极：活泼金属失电子，被氧化；正极：氧化剂得电子，被还原。
  • 闭合回路：电子走导线，离子走电解质溶液。

公式与推导

负极：Zn − 2e⁻ = Zn²⁺（氧化）　｜　正极：2H⁺ + 2e⁻ = H₂↑（还原）
总反应 Zn + 2H⁺ = Zn²⁺ + H₂↑。判断口诀：两极一液一回路；活泼金属为负极。

生活连结

  • 干电池、手机锂电池都是"自带电解质的原电池组"。
  • 轮船船体焊上锌块"牺牲阳极"防腐蚀。
  • 水果电池：插两种金属片就能点亮 LED——原理同款。

常见迷思

  • ❌「电子穿过溶液」→ 电子只走导线，溶液中靠离子定向移动。
  • ❌「铜被腐蚀」→ 铜是正极只导电，锌才被腐蚀。
  • ❌「正负极看位置」→ 看活泼性与反应，不是看画在左边还是右边。
📝 老师备课卡
教学目标：能指认正负极、写电极反应式、说清电子与离子的流向。
开场提问："为什么铜板上冒泡，锌板上却不冒？"
活动：拖酸浓度看气泡速度，追问本质（c(H⁺) 增大）。
总结金句："负失氧、正得还，电子外路转一圈。"
⑪ 电解池：电能 → 化学能
电解 CuCl₂ 溶液：阳极氯离子放电出氯气，阴极铜离子放电镀铜。电压要够"劲"才推得动非自发反应。
阳极：2Cl⁻ − 2e⁻ = Cl₂↑
阴极：Cu²⁺ + 2e⁻ = Cu
状态：电解中
5.0

核心概念

  • 电解池把电能转化为化学能，可驱动不能自发进行的氧化还原反应。
  • 阳极接电源正极，发生氧化反应；阴极接电源负极，发生还原反应。
  • 离子放电顺序（阳极）：S²⁻>I⁻>Br⁻>Cl⁻>OH⁻；（阴极）Ag⁺>Cu²⁺>H⁺>…

公式与推导

阳极：2Cl⁻ − 2e⁻ = Cl₂↑　｜　阴极：Cu²⁺ + 2e⁻ = Cu
与原电池对偶记忆："阳氧阴还"（电解池阳极氧化）恰好与原电池相反，先定电极名再写反应。

生活连结

  • 电解精炼铜：粗铜做阳极，纯铜在阴极"长"出来。
  • 电镀：镀件做阴极，镀层金属做阳极。
  • 氯碱工业：电解饱和食盐水制 Cl₂、H₂ 和 NaOH。

常见迷思

  • ❌「阴阳极与正负极混着叫」→ 电解池说阴阳极，原电池说正负极。
  • ❌「阳极总是惰性电极」→ 活性金属做阳极时金属本身优先溶解。
